# Portafolio de Julio Martínez Flores

Portafolio web personal de evidencias académicas de Ingeniería en Desarrollo de Software. Está desarrollado con HTML5, CSS y JavaScript.

## Personalización

Edita `datos.js` para actualizar nombre, presentación, ubicación, correo, GitHub, formación, tecnologías y proyectos.

### Fotografía

La fotografía está pendiente. Para agregarla:
1. Guarda tu imagen dentro de `assets/` con el nombre `perfil.jpg`.
2. Abre `datos.js`.
3. Cambia `foto: ""` por `foto: "assets/perfil.jpg"`.

### Proyectos

Las fichas de proyecto se encuentran en la carpeta `proyectos/`. Los enlaces de las tarjetas llevan a páginas descriptivas dentro de este mismo portafolio. Agrega enlaces a repositorios individuales cuando estén disponibles; no se han inventado repositorios para los proyectos.

## Publicar en GitHub Pages

1. Abre el repositorio `portafolio` de tu cuenta `jmf52`.
2. Selecciona **Add file → Upload files**.
3. Descomprime este ZIP en tu computadora y arrastra TODO el contenido de la carpeta (incluidos `index.html`, `datos.js`, `.nojekyll`, `assets`, `css`, `js`, `demos` y `proyectos`) al área de carga de GitHub.
4. Selecciona **Commit changes**.
5. Entra en **Settings → Pages**.
6. En **Build and deployment**, selecciona **Deploy from a branch**, rama `main` y carpeta `/(root)`. Guarda.
7. Cuando aparezca **Visit site**, abre tu sitio publicado.

La dirección esperada para el repositorio de proyecto es `https://jmf52.github.io/portafolio/`.
